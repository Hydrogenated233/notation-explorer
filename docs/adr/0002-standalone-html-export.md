# Export standalone HTML with CDN libraries and a Blob worker

Standalone exports are one downloadable HTML file that embeds the application CSS, runtime code, selected notation files, shared helpers, and detected notation dependencies; fixed versions of Vue, KaTeX, and XLSX load from jsDelivr to keep the artifact smaller. The diagram worker is embedded as source and started from a Blob URL so the application can open directly through `file://`, and every export receives a package ID that namespaces its persisted analysis and settings. The generated read-only file list also exposes the embedded source copy of each bundled notation file as a local Blob download; runtime file entries point to an indexed source descriptor so the source is embedded only once. This deliberately requires network access for third-party libraries, while excluding mutable notation-file management (editing, uploading, enable/disable, and deletion) and repeat standalone-HTML export from the generated application.
